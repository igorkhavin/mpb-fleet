# mpbfleet.com

Website for MPB Fleet Services (MPB Auto Repair & Body Collision, Rancho Cordova).
Hosted free on GitHub Pages; domain mpbfleet.com (Whois.com).

- `index.html` – homepage
- `styles.css` – shared look for every page
- `<industry>/index.html`, `credit-application/`, `thanks.html`, `application-received.html`, `404.html`, `sitemap.xml` – generated by `_build/build.py`
- Forms send to mpbfleet@gmail.com through FormSubmit (formsubmit.co)
